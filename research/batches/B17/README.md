## 三、深搜的三项重点纠偏

1. **商标法公布≠施行**：第77号主席令载明全面修订的商标法2027-01-01才施行；当前2026-11仍需使用现行2022代理管理规定。
2. **旧候选名称不能覆盖新政策**：研学旅行指导师已调整为“研学旅游指导师”，2026颁布职业技能标准；数字孪生工程技术人员已在2026-09-09**正式发布**，不能继续标记“拟新增”。
3. **标准版本不可混用**：生态环境法典2026-08-15施行，2026-09修订行政处罚规章；电池GB 38031-2025已经实施，但BMS推荐性GB/T 38661-2020仍现行、2026修订计划未完成。

## 四、证据分级和主体责任

- **法律/行政规章**：指出生效日期、法律责任主体和法定许可。例如破产管理人由法院指定，铁路公安民警与企业安保岗位分别管理。
- **国家职业技能标准/产品标准**：对人员能力与产品安全分别适用，不能据工程产品标准创造个人执业证。
- **机构与企业招聘**：仅为特定年份、地区、用人主体的岗位职责例证，不可推断全国统一学历/晋升年限。
- **所有职业边**：统一保守标为 `conditional`；前一个岗位资历不保证后一个岗位任职。
