## 二、深度核验发现

| 职业 | 决定性版本或证据 | 研究结论与限制 |
|---|---|---|
| 军队航天专业技术人员 | 军队人才网2027招考公告、军事航天部队单位名录和2024军兵种调整 | 文职技术人员≠现役军官；2027普通报名2026-11-10结束；不得用已撤销战略支援部队番号替代当前机构 |
| 涉外法律服务律师 | 2026-08-28《律师法》修正（9月1日生效）新增涉外法律服务条款 | 必须先具合法律师执业身份，国家并未创设独立统一“涉外律师执照”；国外法律资格按目标法域 |
| 国家统计系统公务员 | 2024-09-13修正《统计法》；国家统计局2026调查队招录公示 | 调查队多为“参公单位工作人员”，不能将参公身份直接等于普通行政公务员，也不得统计造假 |
| 海事行政执法人员 | 2027直属海事局专项招考和2011海事行政执法证件规章 | 机关录用与执法证件均需合法；海事执法与武警海警机构的海上维权执法体系不同 |
| 教育技术应用工程师 | 2025教育数字化九部门政策与2026高校合同聘用招聘 | 教育工程岗位≠教师资格；合同／劳务派遣与事业编身份不能自动等价 |
| 助产士 | 2025助产医疗机构基本标准、2021母婴技术考核管理 | 注册护士资格+助产专项技术考核+合法机构资质，不能只持护理证就独立提供助产 |
| 医院感染管理专员 | 医院感染管理办法、2025年16项WS/T标准、WS/T 592—2026 | 2025标准自2026-02-01实施；WS/T 592—2026直至12月1日才实施；院感专员无统一国家执业证 |
| 推荐算法工程师 | 2022算法推荐管理规定与百度2026岗位原文 | 备案等主体义务落在法定服务提供者而不是工程师个人，开发实践包括召回／排序／A/B |
| 薪酬绩效经理 | 2025职业标准通知、2026公开招聘、《个人信息保护法》第13条 | 企业经理头衔不由职业技能证书自动授予；薪酬绩效数据必须有合法必要性 |
| 非物质文化遗产保护专员 | 2011《非遗法》、2019国家级传承人管理办法与2026地方修订 | 档案和项目保护人员≠经独立认定的国家级代表性传承人；岗位身份按招录机构判断 |

## 三、研究来源与可审计性

每个职业 `route.json` 中 `sources` 记录公开原始 URL、发布机构和日期；节点 `source_ids` 和 Markdown 的证据章节用于解释结论。法规发布、修订、生效日期必须分别核对。具体年度公告仅支持当年职位、地区和用人主体；企业招聘只用于举证岗位任务。未能确认原始日期的招聘链接不冒充官方时间。

完整来源核验与重点条款见 [B16 Evidence Audit](./EVIDENCE_AUDIT.md)。
