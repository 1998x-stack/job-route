## 二、研究焦点与证据核查结果

| 职业 | 最新制度与关键风险 |
|---|---|
| 法院执行辅助人员 | 合同制辅助岗位≠员额法官或司法警察 |
| 省政府办公厅综合文秘干部 | 普通机关考录和在编公务员省直遴选分离 |
| 街道党工委书记 | 区委等上级党委选任≠街道办事处主任 |
| 海警执法人员 | 武警海警与交通海事区分；2+2联合培养调整 |
| 防汛抗旱应急指挥调度员 | 信息值守不拥有行政指挥权；2022预案机构变更 |
| 高校教学副校长 | 2026新高校领导管理办法、教授职称不自动升任 |
| 科技馆科普活动策划师 | 2024科普法下区分雇员、见习与志愿服务 |
| 精神科医师 | 2025国家附条件精神卫生加注、2026地方实施 |
| 自动驾驶感知工程师 | 2027才施行的企业准入与GB 44721—2026 |
| 创业公司首席运营官 | COO头衔与公司法经理、董事、法定代表人不同 |

## 三、研究方法

1. **现行效力优先**：区分法律通过、公布和实施日期；例如自动驾驶GB 44721—2026于2027-07-01实施，2026-11不得认定为现行已施行标准。
2. **多重法律身份分离**：岗位合同、行政编制、武警警官、法定执业资格、专业职称、企业董事/经理及机构授权分别建模。
3. **年度公告只支持其自身**：法院2026聘员、军队2026—2027警官、各省公务员遴选及科技馆见习具有各自时间与地区限制。
4. **组织权限与个人技术能力分离**：值班人员不等于防汛行政指挥负责人；个人感知模型能力不替代车企/产品准入。
5. **路径非保证晋升**：任何箭头均记录为 `conditional`；JSON `source_ids` 指向每项所引用的可核查政策与招聘资料。

## 四、质量验证与网站发布

```bash
python -m pip install -r requirements.txt
python scripts/validate.py
node scripts/generate.mjs --check
python -m unittest discover -s tests -v
python scripts/build.py
python scripts/smoke.py
```

只有 PR CI 成功后方可合并 `main`；合并后再次检查独立主分支 CI、Pages Deploy 工作流、B18文件在 `main` 真实存在以及公开网页的访问状态。

> 更新政策时同时修改 `route.json` 和 `report.md`，再使用仓库 `node scripts/generate.mjs --write` 重新生成 Mermaid 与 SVG，保持机器数据和可视化一致。
