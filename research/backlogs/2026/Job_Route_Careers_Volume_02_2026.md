# Job Route Atlas — 第2批100种职业发展路线研究目录（2026）

> **性质**：职业发展研究候选清单／批次生产计划；不是100份已完成的职业路径报告。
> **研究基准**：2026-11-11；以中国大陆为主。后续实际研究须逐岗核对现行法规、地域与机构。
> **编号**：JR-101–JR-200；本文件与其他批次按 slug 和研究目标去重。

## 执行摘要

第二批100个研究选题使用 JR-101—JR-200，全部与第一批职业标题及唯一slug去重。共有9个分类，分为 B11—B20 共10个可独立执行批次。部分目标是特定组织岗位、专业细分岗位而非《职业分类大典》里的独立职业编码。

**证据边界**：本目录的“入口候选”“路线草案”和“核验问题”属于预研，不是已完成法定任职资格认定；领域级参考链接仅用于下一轮研究起点，不可直接当作每条晋升箭头的证据。

## 与国家职业分类体系的关系

《中华人民共和国职业分类大典（2022年版）》保持八大职业大类、收录1639种职业。Job Route 的九类是研究主题分类，不代表官方职业编码体系。[S01]
取得职业资格、执业注册、机关招录、职级、职称、企业任命及依法选举属于不同事件；不能互相推断。

## SKILL 批量生产规范

每批从10个目标开始，不应把100个规划条目一次性标记为“已发布”。执行步骤：

1. 阅读仓库 `AGENTS.md`、`skills/job-route/SKILL.md`、`schema/career-route.schema.json` 与本批 Markdown。
2. 按目标职位确认国家／地区／机构、适用年度、身份类型与职位性质，检索现行官方法规和当年公告。
3. 逐条建立来源账本；标记 `normative`、`official_description`、`illustrative`、`conditional`；证据不足不补造晋升边。
4. 生成 `data/<category>/<slug>/route.json` 与引用 `![路线图](./route.svg)` 的 `report.md`，由生成器派生 `.mmd` 与 `.svg`。
5. 执行 Schema、来源交叉引用、路径连通性、生成漂移、回归测试、站点 smoke test；合格后提 PR。
6. 合并后分别核查 CI 和 Pages 实际状态，报告新增发布数、待复核数、引用来源数、Commit 与 PR URL。

```bash
python -m pip install -r requirements.txt
node scripts/generate.mjs --write
python scripts/validate.py
node scripts/generate.mjs --check
python -m unittest discover -s tests -v
python scripts/build.py
python scripts/smoke.py
```
